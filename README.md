## 1. 🤖 BEAST — Intelligent Virtual Assistant

An extensible desktop voice assistant built in Python that listens to user voice commands, converts speech to text, executes actions, and speaks back using local text-to-speech synthesis.

### Features
- **Speech-to-Text:** Captures microphone input and converts spoken queries into text using `SpeechRecognition`.
- **Text-to-Speech:** Offline natural audio feedback powered by `pyttsx3`.
- **System Automation:** Opens web browsers, launches applications, and queries APIs.
- **Conversational Logic:** Handles queries, system tasks, and external requests.

### Quick Start (BEAST)
```bash
cd BEAST-main

# Install dependencies
pip install speechrecognition pyttsx3 requests

# Run assistant
python main.py
```

## 2. 🧾 Invoice Generator Web Application

A responsive, modern web application built with React to generate, manage, and print customized invoices.

### Features
- **Dynamic Line Items:** Add items with quantity, rate, and automatic subtotal/tax calculations.
- **Client & Company Profiles:** Enter sender and bill-to information with instant preview.
- **Print / PDF Export:** Clean printable invoice layout with professional formatting.
- **Responsive Interface:** Component-driven architecture using modern React state management.

### Quick Start (Invoice Generator)
```bash
cd Invoice-Generator-main

# Install npm dependencies
npm install

# Start the dev server
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
